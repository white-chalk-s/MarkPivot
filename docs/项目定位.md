# MarkPivot · 项目定位

> 2026-09-23 起，现行产品定位以根目录 [产品定位.md](../产品定位.md) 为准。本文保留转换引擎阶段的历史能力说明。

## 一句话

一个本地运行的文档规范化工具：把已经写好的 Word，按目标模板或规则自动识别、统一格式并批量输出可交付文件。内部仍以 Markdown 作为语义层，以复用既有 Word 解析与导出能力。

## 服务对象

适合需要在 Word、Excel 和 Markdown 之间反复整理材料的个人创作者、文档编辑和小团队。重点是保留结构、图片、脚注、链接和表格，并减少导出 Word 后的手工排版。

## 当前产品能力

- Word、Excel/CSV、Markdown 互转，所有链路经过 Markdown；
- Word 纸面预览可编辑回写，Excel 多 Sheet 网格可编辑回写；
- 格式预设、自定义样式 JSON、参考 Word 样式提取和 Word 导出设置；
- 批量旁路转换、文件打开/刷新/保存/自动同步和转换报告；
- Frontmatter、标签、内部链接、嵌入、Callout、封面、固定表格列宽和 WPS 常见排版兼容。

## 产品边界

- 不提供 Excel↔Word 直转入口，统一走 Markdown 中转；
- 只支持 `.docx`，不支持旧 `.doc`；
- 不做云端存储、账号、实时协作、PPT 或 PDF；
- 不承诺复杂 Word OOXML、OMML 公式、浮动布局和全部 Excel 视觉元数据的完全可逆。

## 成功标准

真实 Word 文档经过 Word→Markdown→Word 后，结构、图片、链接、脚注和表格可检查、可回归；同一份 Markdown 套用不同格式规范时，内容不变、呈现按规范变化；任何无法完整保留的内容都在转换报告中明确提示。当前自动化基线为 `45 PASS / 0 FAIL / 0 SKIP`。
