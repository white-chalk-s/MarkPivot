## 文档职责边界

- README 只做入口，不复制完整技术细节。
- 使用说明只描述用户能做什么和怎么做，不写开发过程。
- 开发文档记录当前实现，不承担历史决策档案职责。
- 交接表是当前开发队列和验收依据，不是用户手册。
- 更新日志记录已发生的变更，不作为未来需求清单。
- 项目总则只保留会影响后续开发的硬约束；具体机制放开发文档。

## 历史归档

`archive/` 当前包含：

- `方案_文档互转工作台_2026-09-02.md`：立项时的完整产品规划，已由现役定位、使用说明和开发文档承接。

- `原型/Excel-Md/`：Excel→Markdown 原型。

归档材料保留用于追溯需求来源和对比原型，不参与当前产品验收。若历史材料中的状态、路径或功能与现役文档冲突，以当前代码、QA 报告和现役文档为准。

## 生成物与源码

`tools/fixtures/`、`tools/baseline*/` 和 `tools/output/` 是开发验证资产。它们不属于用户使用文档，也不应复制到 README 中作为产品功能承诺；需要证明结果时引用对应 QA 报告和版本目录。
