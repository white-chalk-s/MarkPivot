# MarkPivot · 文档互转工作台 · 设计规范（UI Token）

> 面向 UI/前端维护与验收，不是用户操作手册；用户操作见 [使用说明](使用说明.md)。UI 观感单一真源 = 工作台 HTML 的 `:root` 区。本表登记**实际值**，与实现互为镜像（随机抽 3 个值应能在 HTML 找到）。
> 状态标注：**[已落位]**（2026-09-03，U1 视觉范围 + U2/U3/F1 已实现）；未收敛的历史兼容字面值不再作为新视觉 Token 使用，详见更新日志遗留项。
> 注意区分：下表是**工具 UI** 的 Token。「文档默认格式规范」（Word 预览渲染与导出用的排版值）真源在格式规范系统的默认预设（JS 常量），本表仅镜像，见末节。

## 文档默认格式规范（镜像，真源 = 默认预设常量）

| 项 | 默认值 |
| ---- | ---- |
| 文档标题 | 34px / 700 / `#2f5496` / 行高 1.28 |
| H1–H4 | 27/22/18/16px，标题字重 700 |
| 正文 | 15px / 行高 1.78 / `#000000` / 段后 14px |
| 标题梯度 | H1 `#2f5496` · H2 `#4472c4` · H3 `#5b9bd5` · H4–H6 `#5f6b7a` |
| 链接/表格/Callout | 链接 `#0563c1` · 表头 `#d9e2f3` · 网格线 `#b4c7e7` · 提示底 `#eef3f8` |

> V2 说明：正文默认色固定为 `#000000`。Word/OOXML 在正文为黑色时通常省略 `w:color`，平台按规范将缺失字段还原为默认黑，而不是用历史预设色冒充模板提取结果。

### F3 封面结果视图

- 仅正文开头的 `::title` 与可选 `::desc` 组成封面；封面使用独立纸面、顶部 accent 强调线、居中标题和居中副标题。
- 封面副标题不使用普通说明块的左边框和底纹；封面后使用轻量虚线分页标记，标记为结果视图派生节点。
- 移动端保持同一层级，降低封面最小高度与内边距，不改变 Markdown 源语义。

> 深色模式：v1 不做（工具类单场景）。如后续立项，先扩 Token 不改结构。
